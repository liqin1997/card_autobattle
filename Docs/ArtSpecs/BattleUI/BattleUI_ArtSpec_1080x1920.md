# 战斗界面美术接入规范（1080×1920）

> `BattleUI_CleanMockup_1080x1920.png` 是静态切图基准：已主动关闭 CD 扫光、弹道、跳字、粒子、全屏噪点和跨区域暗角。以上内容必须作为 Unity 运行时独立层实现，不得烘焙进公共背景或卡牌插画。

## 1. 基准与交付

- 设计基准：竖屏 `1080×1920 px`，Unity 根 Canvas `Scale = 1`。
- 所有坐标均为左上角原点的最终显示像素，不再使用 540×960 逻辑尺寸换算。
- 美术 PSD 建议按 `1080×1920` 建立；单卡插画母版按显示尺寸的 2 倍绘制，最终由 Unity 或导出流程缩放。
- 全屏背景必须四边各多留至少 `32 px` 出血；关键文字和按钮不得进入顶部/底部设备安全区。

## 3. Slot 与 Card 统一规格

- 所有敌方卡、主角、召唤物、主动技能和被动卡：显示 Rect 统一为 `288×184 px`。
- 棋盘单格 Slot 同样为 `288×184 px`，不得因血条、技能充能或弹药条改变高度。
- 单卡母版建议 `576×368 px`（2×）；运行时显示为 `288×184 px`。
- 卡牌外框：`288×184`，建议九宫格 Border `24/24/24/24 px`（按最终显示尺寸）。
- 插画裁切区：`X=8, Y=8, W=272, H=168`；插画必须允许 Cover 裁切，重要主体放在中心安全区。
- 主体安全区：`X=34, Y=34, W=220, H=104`，关键头部、武器和轮廓不得超出。
- 左上数值区：`X=16, Y=12, W=92, H=42`；图标 28×28，数字字号建议 30–34。
- 右上标签区：`X=174, Y=12, W=98, H=38`；标签图标 30×34，文字字号 18–20。
- 底部状态区：`X=14, Y=146, W=260, H=28`；生命、护盾、治疗、充能和弹药全部复用这一固定区域。
- 有生命单位：状态区展示图标、血条和 `当前/最大` 数字。
- 无生命技能牌：状态区改为 CD 分段、弹药、蓄能或常驻标记；禁止删掉状态区后放大插画，否则会破坏阵列统一性。

## 4. CD 扫光与状态表现

- 扫光只作用于插画区和框内内容，不覆盖外框、标签及底部数值文字。
- 未扫到区域使用约 `55%` 黑色遮罩；已扫过区域恢复原插画亮度。
- 扫描线高度建议 `6 px`，外加上下各 `14 px` 柔光；从下向上推进。
- 敌我双方复用同一套 Shader，敌方强调色为暗红/橙红，我方为冷青；发光仅改变参数，不制作两套尺寸不同的资源。
- 受击闪白、击退、跳字和弹道均在卡牌外部效果层完成，不能改变 Card RectTransform。

## 5. PSD 分组与 Unity 切图

建议每张卡牌母版保持以下固定分组：

1. `00_Guide`：尺寸线、安全区、九宫格线，导出时关闭。
2. `01_Shadow`：卡牌投影，单独切图或由 Unity 材质实现。
3. `02_Frame`：统一外框，九宫格 Sprite。
4. `03_Artwork`：单卡插画，单独矩形 Sprite。
5. `04_TopStat`：左上图标与数值；数值由程序生成，PSD 只提供图标底板。
6. `05_Tag`：右上标签徽章；主标签与副标签只更换图标和颜色。
7. `06_StatusBase`：底部状态槽底图，所有卡通用。
8. `07_StatusFill`：血量、护盾、充能和弹药填充，由程序控制宽度或格数。
9. `08_CDMask`：不切静态图，使用 Unity Shader/MaterialPropertyBlock 控制。

推荐切图命名：`battle_card_frame_common`、`battle_card_status_base`、`battle_card_tag_badge`、`battle_card_icon_*`、`battle_card_art_*`。颜色差异尽量通过材质参数完成，避免重复输出同尺寸但仅颜色不同的 Sprite。

## 6. 验收红线

- 18 个棋盘位置的 Card Rect 必须全部是 `288×184 px`。
- 有血条和无血条卡牌的外框、插画区、标签区、底部状态区位置必须完全一致。
- 任意卡牌替换后不得引起 GridLayout、相邻关系计算、弹道中心点或跳字中心点变化。
- 文字不得烘焙进通用外框；动态数值、标签、关卡和任务信息全部由程序生成。
- 美术资源接入后，应在 1080×1920 Game View 中进行像素对齐验收，并额外检查异形屏安全区。
