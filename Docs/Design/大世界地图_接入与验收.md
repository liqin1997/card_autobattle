# Commercial 大世界地图接入

更新日期：2026-08-27。以本轮最后确认的“区域挂机＋任务驱动世界探索”规则为准，不采用线性自动跳关，也不排队等待 Boss 战。

## 入口与流程

- 场景：`Assets/Scenes/CommercialVerticalSlice.unity`。
- 主城 → 世界地图；或探索两方棋盘中间的地图预览 → 前往大地图。
- 打开地图只切换显示，当前战斗继续在后台运行。
- 拖动地图可平移；滚轮、双指、底部滑条可缩放；定位按钮回到当前战斗位置。
- 点击营地图标切换挂机区域；点击精英或首领并确认，立即中断原战斗、清理其弹道与跳字，开始目标战斗。
- 被中断的这场没有胜利奖励、不增加任务计数；已累计的任务进度和已领取物品保留。
- 事件挑战胜利后恢复原挂机区域；失败停留结果 3 秒后恢复原挂机区域。普通挂机失败停住，支持换装/调整阵容后重试或去其他区域。
- 探索中间地图始终显示当前实际战斗的区域，而不是大地图上临时拖动浏览的位置。

## 首版内容与任务

五个区域：灰烬森林、鸦羽丘陵、荒沙古城、霜落雪原、终焉王座。

每区 5 个节点：挂机营地、支线委托、精英、首领、宝箱，共 25 个节点。当前采用固定可编辑位置，不宣称已接入随机刷新、每日重置或服务器任务系统。

主线任务初始自动接取当前区域：区域挂机胜利 5 次＋击败本区域首领。手动领奖后解锁下一区域；点击“探索区域”驱散新区域迷雾。任务日志支持前往挂机目标/首领、查看计数和领奖。

支线委托需要手动接取，接取后击败该区域精英才能完成。支持跟踪并立即前往目标战斗、领奖。宝箱每个存档领取一次。首领和精英首次提供装备奖励，重复挑战保留基础经验/金币。

`CommercialWorldMapData.cs` 集中定义区域、节点位置、任务条件、奖励和解锁规则；后续可替换为策划配置资产。现有 Chapter/Stage 数值表仅用于构建遭遇难度，本入口不再调用自动跳关结算。

## 场景与渲染

```text
CommercialGameRoot
├─ WorldMapSceneRoot（独立 CommercialWorldMap Layer）
│  ├─ 01_TerrainLayer          素材目录1＋地表补片
│  ├─ 02_SceneryLayer          目录2：树木、山脉
│  ├─ 03_BuildingsLayer        目录3：村庄、城堡
│  ├─ 04_ObjectsLayer          目录4：营地、怪物、宝藏
│  └─ 05_FogLayer              持久化探索迷雾
├─ WorldMapCamera             独立正交相机，仅渲染地图层
├─ WorldMapCanvas             全屏地图操作界面，1080×1920参考尺寸
│  └─ Page_WorldMap
│     ├─ MapViewport / 06_EventButtonLayer（目录5图标）
│     ├─ TaskLog
│     ├─ WorldEventDetail
│     └─ MapControls
└─ BattlePresentationRoot / BattleInfoLayer / BattleTimeline
   └─ WorldMapPreview         中间地图窗口，仍在弹道/特效下层
```

地图主体为 SpriteRenderer，不把植被和地形拆成大量 UGUI Image。相机输出到共享 1024×1024 RenderTexture，按显示窗口设置相机宽高比，避免地图拉伸。全屏与小窗共用一份输出，不开两台地图相机。

全屏模式显示地图专用 UI，隐藏原顶部栏、底部导航和战斗画面。非地图页面停用地图相机；探索预览最多约 10 次/秒渲染。迷雾为 256×256 动态纹理，只在探索数据改变时重绘。事件按钮复用，地形使用共享无光照材质，无物理碰撞、无额外灯光或后处理。

参考分辨率保持 1080×1920，战斗卡牌仍为 288×184；未改卡牌扫光、职业、装备和邻接公式。

## 存档与预制体

旧角色、装备、职业存档沿用原键并补齐 World 字段。地图保存当前位置、挂机位置、已探索节点、支线状态、主线任务计数、领奖状态。读取存档时重新开始该区域挂机，不重放中断战斗的奖励。

新增预制体：`PF_WorldMap_SpriteWorld`、`PF_Screen_WorldMap`、`PF_WorldMap_ExplorePreview`；更新主城、战斗展示与 Commercial 根预制体。原素材包资源不移动、不删除。

安装工具：`Tools/Card Autobattle/Install World Map Into Commercial Scene`。只向现有 Commercial 场景安装一次；再次调用不覆盖手工调整。原完整场景生成器也已接入地图，但不要为调整地图而重新生成整个场景。

## 验收记录与边界

- 自动检查：47 项数据/战斗检查＋17 项运行时 UI/切换检查。
- 已验证：真实精英/首领战、三职业战斗、战中换位、立即中断、旧战斗不结算、结算只执行一次、任务与宝箱防重复领奖、任务解锁区域、迷雾访问限制、存档往返。
- 实测打开大地图后，战斗时间和结算序号继续增长；返回探索未重新创建该场战斗。
- 场景引用检查：0 个丢失脚本；所有战斗卡牌尺寸仍为 288×184。
- 验收辅助：`CommercialWorldMapAcceptance.RunDataChecks()` / `RunRuntimeChecks()`；后者只在 Play Mode 执行并恢复测试前状态及存档，结束后会暂停控制器更新供截图检查。
- 以上为 Unity Editor 验证，不等于所有设备无 bug；尚未做 Android/iOS 真机帧率、内存、触摸手感与长时间挂机压测，也未增加离线收益/联网同步。
