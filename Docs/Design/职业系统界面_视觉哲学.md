# 灰烬刻度

“灰烬刻度”以被烟火熏黑的羊皮、磨损金属与手工刻痕构成视觉世界。空间不是光滑的数字容器，而像一张被长期使用、反复批注的职业研究图谱；身份、成长与力量通过层层嵌套的框架、刻度和符号被观察。所有结构必须经过精密推敲，呈现出顶级设计师耗费无数时间雕琢的手工秩序。

构图依赖明确的重心与克制的非对称。职业头像作为左侧沉重锚点，属性加点形成中部纵向节拍，职业资源与机制说明在右侧收束。信息不是平均铺开，而是通过面积、明暗、边缘磨损程度与留白自然分级；每条对齐线都应具有大师级的准确，每个间距都像经过反复校正。

颜色从炭黑、旧纸褐和骨白中生长，只用少量职业色作为活性信号：战士的锈红、游侠的冷绿、法师的幽蓝。职业色不大面积涂抹，而像能量渗入裂纹、印章和进度刻度。材质层次需要细致而可信，金属、纸张、墨迹与微光必须拥有经得起近看的精工质感。

尺度形成仪式感：头像与职业名称宏大而安静，属性数字清晰有力，解释文字退居次要。文字只承担必要锚点，绝不依靠长段落解释界面；职业特性通过资源环、触发链符号和简短标签表达。字体与图形应融为同一件艺术品，呈现出长期打磨后的专业完成度。

最终作品应像一件来自虚构学派的职业测绘仪器——既是角色养成界面，也是可被研究的战斗结构图。所有纹理、框线、图标和光点都服从同一套严谨语法，避免装饰堆积；以极端克制和痛苦般细致的工艺，让玩家一眼读懂身份、投入与回报，同时感到这套系统拥有深不可测的成长空间。
