# 灰烬森林：新档探索样板

交付日期：2026-08-28。场景：`Assets/Scenes/CommercialVerticalSlice.unity`。

## 从哪里开始

新档为 Lv.1、经验 0、未穿装备、任务未接取。进入游戏自动打开灰烬营地的第一条任务，接任务前不启动挂机。点击「接取任务」→「追踪任务目标」→「切换挂机区域」开始。

战斗期间可以切换其他切页或打开地图，战斗仍按时间推进。点击精英或首领的「立即挑战」会替换当前战斗，未完成的旧战斗不结算奖励。战斗界面中央显示实际地点，地图预览沿用当前挂机／战斗位置。

## 必经体验路线

| 阶段 | 玩家操作 | 保证获得的成长 | 开放内容 |
|---|---|---|---|
| 营地求援 | 接取后，在营地外围胜利 2 次；打开任务手动领奖 | 120 金币、35 经验、Lv.4 蓝色铁誓主武器、木材 4。最短路径升到角色 Lv.2，可立即穿戴武器 | 雾林哨塔 |
| 林场清障 | 接任务，调查哨塔，击败林场守卫，领奖 | 160 金币、80 经验、Lv.6 蓝色铁誓护甲、木材 6、锻造尘 3。最短路径升到 Lv.3，两件装备形成套装 | 矿洞、矿箱、断桥 |
| 修复断桥 | 接任务；拾取矿箱或矿洞挂机获得铁矿；交付木材 8、铁矿 4，再领取任务奖励 | 200 金币、120 经验、锻造尘 8。最短路径升到 Lv.4，可用已有金币和尘强化武器 | 林心营地、树碑、首领任务 |
| 驱散林心阴影 | 接任务；穿好两件铁誓装备，强化主武器一次；挑战灰烬树王，手动领奖 | 300 金币、100 经验、Lv.8 紫色铁誓头部装备、探索徽记 1 | 鸦羽隘口 → 鸦羽丘陵 |

任务面板的「前往装备」可直接打开装备切页。装备从仓库点开详情后穿戴，强化需要再次确认。换装与强化不改变已经开打的战斗快照，下一场战斗正常采用最新属性。

地图的「任务日志」打开当前主线任务；「追踪目标」定位当前缺少的步骤：未接取／可领奖时返回营地，调查前定位哨塔，缺矿时定位矿箱或矿洞，材料齐全后定位断桥。

## 可选探索支路

- 遗落行囊：获得一个装备箱，在背包物品仓库自行开启。
- 隐藏木材堆：一次性获得木材 8，也可用营地挂机作为持续来源。
- 废弃矿洞：反复挂机，每胜利一次获得铁矿 1～3，同时保留经验与随机装备掉落。
- 古老树碑 → 封印宝箱：调查获得古老钥匙，消耗钥匙开箱，获得史诗装备箱。不是通关强制条件。
- 林心营地：更高难度的挂机点，可继续获取装备和经验。

共 14 个地点。新档只发现 3 个营地地点；任务领奖和调查事件逐步揭示后续地点及迷雾。拖动相机不会绕过任务门槛。一次性事件、任务奖励均防重复；修桥材料不足时不会扣除部分材料。

## 实现和配置

- 保持现有 2D SpriteRenderer 地图、独立地图相机、共享地图 RenderTexture、UGUI 事件按钮，不改核心战斗绘制方式。
- `WorldMapSceneRoot/AshenForestSample` 保存灰烬森林地标、树木、河流与探索路线；原区域 1 旧布局仅停用，未删除资源。
- 地图事件 UI 使用地图相机投影，屏幕外隐藏，拖到视野内再显示；地标和路线根据探索数据启停。
- 存档记录四段任务、接受状态、胜利计数、已发现／已完成节点、材料及装备。已完成旧区域 1 的存档兼容为森林样板已完成。
- 内容与数值配置：`Assets/Resources/Commercial/World/AshenForest.json`。卡牌、装备、背包仍使用各自既有配置。
- 对应场景、地图预制体、地图页面预制体、商业化根预制体已保存。

本轮完整制作的是灰烬森林及进入下一地区的闭环；鸦羽丘陵之后继续沿用既有区域内容，没有在本轮扩写成同等完整的新区域。
